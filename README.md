# أداة تنظيف وتجهيز البيانات | Data Cleaning Toolkit

أداة بلغة `Python` تأخذ أي ملف `CSV` خام، تشخّص مشاكله، تنظّفه بخطوات موثّقة،
وتُخرج ملفاً نظيفاً + تقرير مقارنة قبل/بعد.

بُنيت لأن أغلب مشاريع تحليل البيانات يضيع فيها الوقت في التنظيف قبل التحليل،
والخطوات نفسها تتكرر في كل مشروع.

---

## ماذا تفعل الأداة

| الخطوة | الوصف |
|---|---|
| `standardize_columns` | توحيد أسماء الأعمدة: حروف صغيرة، بدون مسافات أو رموز |
| `drop_duplicates` | حذف الصفوف المكررة تماماً |
| `clean_text` | إزالة المسافات الزائدة وتوحيد النصوص وتحويل `NA` و `-` إلى قيم فارغة حقيقية |
| `drop_empty_columns` | حذف الأعمدة التي تجاوز الفراغ فيها حداً معيّناً (افتراضياً 60%) |
| `fix_dtypes` | تصحيح الأرقام والتواريخ المخزّنة كنص |
| `fill_missing` | الوسيط للأعمدة الرقمية، والأكثر تكراراً للأعمدة الفئوية |
| `flag_outliers` | رصد القيم الشاذة بطريقة `IQR` — **ترصد ولا تحذف**، والقرار للعميل |

كل خطوة تُسجَّل في `log`، فيظهر في التقرير النهائي ماذا تغيّر بالضبط ولماذا.

---

## طريقة الاستخدام

```python
from data_cleaner import DataCleaner

dc = DataCleaner("raw.csv", missing_threshold=0.60)

dc.profile()                  # جدول تشخيص لكل عمود
dc.clean()                    # تنفيذ خطوات التنظيف
dc.save("clean.csv")          # حفظ الملف النظيف
dc.report("report.html")      # تقرير قبل / بعد
```

## مثال تطبيقي: مجموعة بيانات Titanic

شغّل الملف:

```bash
python demo_titanic.py
```

المشاكل في البيانات الخام:

- `177` قيمة مفقودة في عمود `age`
- `688` قيمة مفقودة في عمود `deck` — أي 77% من العمود
- `107` صف مكرر تماماً

النتيجة بعد التنظيف:

| المؤشر | قبل | بعد |
|---|---|---|
| الصفوف | 891 | 780 |
| الأعمدة | 15 | 14 |
| الخلايا الفارغة | 869 | 0 |
| الصفوف المكررة | 107 | 0 |

![القيم المفقودة قبل وبعد](outputs/01_missing_before_after.png)

**ملاحظة على المنهج:** ملء القيم المفقودة قد يجعل صفوفاً مختلفة تتطابق،
لذلك تُعاد خطوة فحص التكرار مرة أخرى بعد الملء — وهي خطوة يغفلها كثيرون
فتظهر تكرارات جديدة في الملف النهائي.

---

## قرارات تصميم مقصودة

- **القيم الشاذة تُرصد ولا تُحذف.** حذفها قرار يخصّ سياق العمل لا الأداة:
  فاتورة بـ 60 ألف قد تكون خطأ إدخال، وقد تكون أهم عميل في الشركة.
- **حد حذف الأعمدة قابل للتعديل** عبر `missing_threshold`، لأن 60% مناسبة
  لبيانات عامة وغير مناسبة لبيانات طبية مثلاً.
- **الملء بالوسيط لا بالمتوسط** في الأعمدة الرقمية، لأن الوسيط لا يتأثر
  بالقيم الشاذة.
